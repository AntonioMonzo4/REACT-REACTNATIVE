# 🚀 Roadmap Profesional de React y React Native

> Repositorio donde documentaré todo mi aprendizaje sobre **React** y **React Native**, desde los fundamentos hasta un nivel profesional orientado al desarrollo frontend y móvil.

## 🎯 Objetivos

- Aprender React desde cero hasta nivel profesional.
- Dominar React Native para desarrollo móvil.
- Comprender cómo se trabaja en proyectos reales.
- Crear un portfolio profesional.
- Aprender buenas prácticas, arquitectura y testing.
- Estar preparado para trabajar como Frontend Developer.
