TypeScript es un lenguaje de programación en Javascript. 

Beneficios de Typescript: 
-Tipado estático 
-Código complementario
-Refactor

Desventajas: 
-Compilador 
-Disciplina/ser más metódico

Para utilizarlo tenemos que descargar Node.js e instalar Typescript 
pnpm add -D typescript 

Si lo haxcemos con React se instalara solo 

Pare ejecutarlo: 
pnpm tsc index.ts
